# Contributing to KreativeZero

Contributions to KreativeZero are welcome!

## Local Development

1. Fork and clone the repository.
2. Install dependencies: `npm install`
3. Install Playwright Chromium: `npx playwright install chromium`
4. Set up database: `npx prisma db push`
5. Start development server: `npm run dev`

Open http://localhost:3000 to see your changes.
